# ❓ Quiz — Prompt Engineering Avanzado

## 📝 Instrucciones

10 preguntas · 6 minutos · una sola respuesta correcta salvo que se indique.

---

**1.** ¿Qué es un prompt?

- a) El nombre del modelo de lenguaje
- b) La instrucción y la información que se le entregan al modelo
- c) Un tipo de base de datos
- d) La respuesta que devuelve el modelo

**2.** Verdadero o falso: un prompt con rol, tarea, contexto y formato suele dar mejores resultados que un pedido vago.

**3.** Este prompt: *«Traduce al inglés: "Nos vemos mañana a las cinco."»* es un ejemplo de…

- a) Zero-shot
- b) One-shot
- c) Few-shot
- d) Ajuste fino

**4.** ¿Para qué sirve principalmente el ejemplo de un one-shot?

- a) Para enseñar al modelo un idioma nuevo
- b) Para fijar el formato, el tono o el criterio de la respuesta
- c) Para cambiar los parámetros del modelo
- d) Para que el modelo recuerde la conversación para siempre

**5.** Verdadero o falso: con un few-shot, el modelo modifica sus parámetros y recuerda los ejemplos en otras conversaciones.

**6.** ¿Cuál es el mejor conjunto de ejemplos para clasificar opiniones?

- a) Cuatro opiniones positivas, escritas de cuatro formas distintas
- b) Una opinión de cada categoría, con el mismo formato, y un caso difícil
- c) Diez ejemplos largos y repetidos
- d) Ejemplos con etiquetas distintas para la misma frase

**7.** Empareja cada error con su efecto:

| Error | Efecto |
|---|---|
| 1. Etiquetas contradictorias | A. Respuestas con formato desordenado |
| 2. Todos los ejemplos de una sola categoría | B. Resultados inconsistentes |
| 3. Ejemplos con formatos distintos | C. El modelo tiende a responder siempre esa categoría |

**8.** Una clínica ficticia quiere clasificar consultas como "Urgente" o "Normal" con **reglas propias**. ¿Qué nivel conviene más?

- a) Zero-shot, porque es la tarea más común
- b) One-shot, porque solo se necesita el formato
- c) Few-shot, porque hay un criterio propio con fronteras difíciles
- d) Ninguno: no se puede hacer con prompts

**9.** ¿Cuál es una limitación real del prompting con ejemplos?

- a) Los ejemplos no cuestan nada
- b) Los ejemplos ocupan espacio en la ventana de contexto y suben el costo
- c) El modelo nunca varía su respuesta
- d) Los ejemplos garantizan que no habrá alucinaciones

**10.** Un asistente debe responder con un manual interno de 300 páginas. ¿Cuál es el siguiente paso más adecuado?

- a) Poner todo el manual en cada prompt, sin importar el límite
- b) Usar RAG para consultar los documentos antes de responder
- c) Añadir más ejemplos zero-shot
- d) Repetir la pregunta varias veces
