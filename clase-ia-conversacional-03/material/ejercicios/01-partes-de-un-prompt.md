# 🟢 Ejercicio 01 — Partes de un prompt

## 📊 Dificultad

🟢 Básico

## 🎓 Resultados de aprendizaje

OA-1

## 🧩 Problema

Lee este prompt de la biblioteca ficticia «Casa del Libro»:

```text
Eres bibliotecario amable. Explica a un niño de 10 años cómo pedir un libro
prestado. Usa tres pasos numerados. No uses palabras técnicas.
```

## 🪜 Pasos

1. Señala en el texto el **rol**, la **tarea**, el **formato** y la **restricción**.
2. ¿Qué pieza falta? ¿Qué **contexto** podrías añadir?
3. Explica en una frase por qué este prompt es mejor que "Explica cómo pedir un libro".

## 📏 Criterios de evaluación

- Identifica las cuatro piezas presentes.
- Propone un contexto útil (por ejemplo, horarios o requisitos del carné).
- Explica que un prompt más claro reduce las respuestas vagas.
