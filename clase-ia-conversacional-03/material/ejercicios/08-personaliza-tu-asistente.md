# 🟡 Ejercicio 08 — Personaliza tu asistente

## 📊 Dificultad

🟡 Intermedio

## 🎓 Resultados de aprendizaje

OA-6, OA-7, OA-8

## 🧩 Problema

Inventa un negocio ficticio (por ejemplo, una veterinaria o una librería) y diseña un asistente de atención.

## 🪜 Pasos

1. Escribe **datos del negocio** (3 o 4 líneas: horarios, políticas, servicios). Todo ficticio.
2. Escribe el prompt con **rol, contexto, formato y restricciones**.
3. Decide el nivel (zero, one o few-shot) y, si hace falta, incluye **2 o 3 ejemplos**.
4. Escribe una consulta cuyo dato **no esté** en tu contexto y di qué debería responder el asistente.
5. ¿Qué pasaría si el negocio tuviera 300 productos? ¿Qué sería lo siguiente?

## 📏 Criterios de evaluación

- Datos ficticios y un prompt con al menos tres piezas.
- Justifica el nivel elegido; los ejemplos son variados y consistentes.
- El asistente deriva o dice que no sabe (no inventa).
- Menciona RAG como siguiente paso cuando el contexto es muy grande.
