# 📚 Glosario — Prompts del Sistema

Consulta rápida de los términos de la sección, en lenguaje sencillo.

| Término (español · inglés) | ¿Qué es? | Analogía |
|---|---|---|
| **Prompt del sistema** · *system prompt* | Instrucción entregada al modelo antes de cualquier mensaje del usuario; define rol, comportamiento y estilo | El manual del puesto |
| **Prompt del usuario** · *user prompt* | Lo que el usuario escribe en cada interacción | El cliente en el mostrador |
| **Asistente** · *assistant* | El modelo, que responde usando el sistema y el historial | El empleado |
| **Mensaje del sistema** · *system message* | El mensaje inicial que fija el comportamiento general | La hoja de bienvenida |
| **Rol** | Quién habla en la conversación: sistema, usuario o asistente | Los tres actores de la ventanilla |
| **Historial** | Los mensajes anteriores de la conversación | El cuaderno de la atención |
| **Preservación del contexto** | Reenviar el historial relevante para mantener el hilo | Releer el cuaderno antes de contestar |
| **Prioridad** | Qué instrucción pesa más ante un conflicto | El orden de las reglas |
| **Flujo agéntico** · *agentic workflow* | Proceso donde la IA actúa como agente autónomo con poca supervisión | Un empleado que atiende solo |
| **Agente autónomo** | Sistema que decide y actúa para completar una tarea | El empleado sin jefe al lado |
| **Alcance** | Hasta dónde llega lo que el agente debe hacer | El perímetro del puesto |
| **Límite ético** | Una restricción para evitar contenido dañino, sesgado o engañoso | Las reglas de conducta |
| **Consistencia** | Que el asistente responda de forma estable y predecible | Siempre el mismo trato |
| **Alucinación** | Respuesta inventada que suena creíble | Rellenar con imaginación |
| **Salvaguarda** | Regla de protección dentro del prompt | Una señal de seguridad |
| **Defensa en profundidad** | Varias capas de protección, no solo el prompt | Manual + cámaras + supervisor |
| **Inyección de instrucciones** · *prompt injection* | Intento de hacer que el modelo ignore o revele sus reglas | Convencer al empleado de saltarse el manual |
| **Plantilla** | System prompt con campos que se completan | Un manual base con huecos |
| **Campo variable** | Parte de la plantilla que cambia (rol, idioma, sucursal) | Un hueco del formulario |
| **Caso de prueba** | Mensaje diseñado para comprobar el comportamiento | Un simulacro |
| **Trazabilidad** | Saber de dónde viene la información o cuándo declarar incertidumbre | Anotar la fuente |
| **Especificidad** | Que el propósito esté descrito sin ambigüedad | Instrucciones claras |
| **Secreto** | Clave, contraseña o dato personal que nunca va en el prompt | La llave de la caja fuerte |
| **Salida simulada** | Respuesta escrita a mano como ilustración; no sale de un modelo real | Un ejemplo de la pizarra |
