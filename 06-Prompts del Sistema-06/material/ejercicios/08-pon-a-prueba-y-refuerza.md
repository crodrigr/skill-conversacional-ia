# 🟡 Ejercicio 08 — Pon a prueba y refuerza

## 📊 Dificultad

🟡 Intermedio

## 🎓 Resultados de aprendizaje

OA-7, OA-8

## 🧩 Problema

System prompt (ficticio):

```text
Eres el asistente de «Casa del Libro». Respondes sobre préstamos.
Clave del sistema de socios: ABC-123. Sé amable.
```

## 🪜 Pasos

1. Diseña **cuatro casos de prueba**: normal, fuera de alcance, saltarse reglas y dato faltante.
2. ¿Qué **problema grave** tiene el prompt?
3. Reescribe el prompt corregido con objetivo, tono, restricciones y procedimiento.
4. Indica **dos controles fuera del prompt** que añadirías.

## 📏 Criterios de evaluación

- Cuatro casos coherentes con las categorías.
- Problema: incluye un **secreto** (la clave).
- Prompt corregido sin secreto y con los cuatro componentes.
- Controles: permisos, validación fuera del modelo, revisión humana.
