# 🟢 Ejercicio 01 — ¿Sistema o usuario?

## 📊 Dificultad

🟢 Básico

## 🎓 Resultados de aprendizaje

OA-1

## 🧩 Problema

Indica si cada frase es un **system prompt** o un **user prompt**:

1. «Eres un asistente de biblioteca amable y breve.»
2. «¿Hasta cuándo puedo devolver este libro?»
3. «Respondes solo sobre préstamos y horarios.»
4. «Dame un resumen del capítulo 2.»
5. «No inventes datos; si no sabes, dilo.»

## 🪜 Pasos

1. Clasifica las cinco frases.
2. Explica con una frase qué **cambia en cada interacción** y qué **permanece**.

## 📏 Criterios de evaluación

- System: 1, 3 y 5. User: 2 y 4.
- Cambia el mensaje del usuario; permanece el system prompt.
