# 📚 Glosario — Fundamentos de Embeddings

Consulta rápida de los términos de la sección, en lenguaje sencillo.

| Término | ¿Qué es? | Analogía |
|---|---|---|
| **Embedding** | Vector (lista de números) que representa el significado de un texto | Las coordenadas de una ciudad |
| **Vector** | Lista ordenada de números | Un punto en un mapa |
| **Dimensión** | Cada número de un vector; los reales tienen cientos o miles | Un eje del mapa |
| **Espacio vectorial** | El "mapa" donde viven los vectores | Un mapa de barrios |
| **Token** | Fragmento de texto: palabra, parte de palabra o signo | Pieza de Lego de texto |
| **Contexto** | Las palabras que rodean a una palabra | Las compañías de una persona |
| **Similitud** | Qué tan parecidos son dos textos (qué tan cerca están sus vectores) | Vecinos de barrio |
| **Distancia** | Qué tan separados están dos puntos | Metros entre dos casas |
| **Similitud del coseno** | Medida de si dos vectores apuntan hacia el mismo lado | Dos flechas con el mismo rumbo |
| **Búsqueda por significado** | Encontrar textos parecidos aunque no compartan palabras | Entender la idea, no solo las palabras |
| **Analogía vectorial** | Aplicar la relación entre dos palabras a una tercera (rey − hombre + mujer ≈ reina) | Repetir el mismo paso en el mapa |
| **Sesgo** | Prejuicio heredado de los textos de entrenamiento | Un reflejo, no una opinión |
| **Word2Vec** | Embeddings de palabras de Google (2013), aprendidos adivinando palabras | Juego de la palabra oculta |
| **CBOW** | Variante de Word2Vec: adivina la palabra a partir del contexto | Completar el hueco |
| **Skip-gram** | Variante de Word2Vec: adivina el contexto a partir de la palabra | Decir con qué suele andar |
| **GloVe** | Embeddings de Stanford (2014) basados en conteos globales de coocurrencia | Registro de la biblioteca |
| **Coocurrencia** | Cuántas veces dos palabras aparecen juntas | Dos nombres en la misma página |
| **Embedding estático** | Un solo vector fijo por palabra | Diccionario con una definición |
| **Embedding contextual** | El vector cambia según la frase | Entender según la conversación |
| **BERT** | Modelo de Google (2018) que lee la frase en ambos sentidos | Crucigrama con letras a ambos lados |
| **GPT** | Modelo de OpenAI (2018) que lee de izquierda a derecha para predecir lo siguiente | Anticipar cómo sigue la frase |
| **Transformer** | Arquitectura (2017) que usa atención y sirve de base de BERT y GPT | Ver el Módulo 01 |
| **Embedding de texto** | Modelo dedicado a producir vectores de frases o documentos | Una ficha por párrafo |
| **Base vectorial** | Almacén que guarda vectores y busca los más cercanos | Un archivo ordenado por significado |
| **RAG** | Consultar documentos antes de responder | Examen a libro abierto |
