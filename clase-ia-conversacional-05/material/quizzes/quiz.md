# ❓ Quiz — Prompts del Sistema

## 📝 Instrucciones

10 preguntas · 6 minutos · una sola respuesta correcta salvo que se indique.

---

**1.** ¿Qué es un **system prompt**?

- a) La respuesta que da el modelo
- b) La instrucción entregada al modelo antes de cualquier mensaje del usuario, que define su rol, comportamiento y estilo
- c) El primer mensaje que escribe el usuario
- d) Un tipo de base de datos

**2.** Verdadero o falso: el system prompt cambia en cada interacción, mientras que el user prompt permanece constante.

**3.** «Eres una IA de narración. Creas historias breves, imaginativas y con tono lúdico.» es un system prompt para…

- a) Atención al cliente
- b) Programación
- c) Escritura creativa
- d) Un asistente financiero

**4.** ¿Por qué se **reenvía** el historial relevante en cada turno?

- a) Porque el modelo no recuerda por sí mismo la conversación y necesita el contexto para no contradecirse
- b) Para gastar más tokens
- c) Porque el usuario lo pide
- d) Para borrar el system prompt

**5.** El sistema dice «no opines de política» y el usuario pide una opinión. ¿Qué es lo más correcto?

- a) Por diseño suele prevalecer el sistema, pero no se puede asegurar que siempre ocurra
- b) El usuario siempre gana
- c) El sistema siempre gana, sin excepción
- d) El modelo elige al azar

**6.** Empareja cada función del system prompt con su ejemplo:

| Función | Ejemplo |
|---|---|
| 1. Definir el alcance | A. «No des recomendaciones personalizadas» |
| 2. Fijar el tono | B. «Responde solo sobre pólizas y siniestros» |
| 3. Marcar límites éticos | C. «Habla de forma cálida y clara» |
| 4. Gestionar expectativas | D. «Indica siempre que la información es general» |

**7.** ¿Qué síntoma suele aparecer cuando falta un system prompt?

- a) Respuestas inconsistentes y pérdida del rol
- b) Respuestas siempre perfectas
- c) Menor costo y mayor precisión garantizada
- d) El modelo deja de responder

**8.** Los cuatro componentes de un system prompt efectivo son…

- a) Saludo, despedida, firma y fecha
- b) Objetivo, tono y estilo, restricciones y procedimiento paso a paso
- c) Pregunta, respuesta, resumen y título
- d) Historial, memoria, herramientas y estado

**9.** ¿Qué significa **defensa en profundidad** para un system prompt?

- a) Escribir un prompt muy largo
- b) Combinar varias capas: reglas explícitas, pruebas y controles fuera del modelo
- c) Poner las reglas al final
- d) Ocultar el prompt y confiar en que nadie lo vea

**10.** ¿Cuál de estas cosas **no** debe incluirse en un system prompt?

- a) El rol del asistente
- b) Las restricciones
- c) Claves, contraseñas o datos personales
- d) El tono de respuesta
