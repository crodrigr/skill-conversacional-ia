# 🟢 Ejercicio 02 — Adivina el caso de uso

## 📊 Dificultad

🟢 Básico

## 🎓 Resultados de aprendizaje

OA-2

## 🧩 Problema

Une cada system prompt con su caso de uso (asistente general, escritura creativa, programación, atención al cliente):

A. «Eres un agente profesional y educado. Respondes con empatía y ofreces soluciones claras.»
B. «Eres una IA que ayuda a escribir código limpio y sigue buenas prácticas.»
C. «Eres una IA de narración. Creas historias breves, imaginativas y con tono lúdico.»
D. «Eres un asistente útil y bien informado. Respondes de forma concisa.»

## 🪜 Pasos

1. Une cada prompt con su caso de uso.
2. Subraya en cada uno la palabra que revela el **rol**.

## 📏 Criterios de evaluación

- A: atención al cliente. B: programación. C: escritura creativa. D: asistente general.
- Identifica palabras como «agente», «código», «narración» y «asistente».
