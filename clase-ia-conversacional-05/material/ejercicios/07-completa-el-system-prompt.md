# 🟡 Ejercicio 07 — Completa el system prompt

## 📊 Dificultad

🟡 Intermedio

## 🎓 Resultados de aprendizaje

OA-7

## 🧩 Problema

Para un asistente ficticio de **«Clínica Sol»** que solo informa sobre horarios y servicios, completa los cuatro componentes:

1. **Objetivo**: ¿qué hace y qué no hace?
2. **Tono y estilo**.
3. **Restricciones**.
4. **Procedimiento** (3 pasos).

## 🪜 Pasos

1. Redacta cada componente.
2. Revisa tu texto con los tres criterios: especificidad, trazabilidad y defensa en profundidad.
3. Marca un campo que podrías volver `{variable}` para otras sucursales.

## 📏 Criterios de evaluación

- Objetivo: informa horarios y servicios; no da diagnósticos.
- Restricciones: no inventar, no consejos médicos.
- Procedimiento de tres pasos.
- Identifica un campo variable (sucursal, horario, idioma).
