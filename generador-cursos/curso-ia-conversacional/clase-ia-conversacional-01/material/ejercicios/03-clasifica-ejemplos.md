# 🟢 Ejercicio 03 — Clasifica en el mapa

## 📊 Dificultad

🟢 Básico

## 🎓 Resultados de aprendizaje

OA-3

## 🧩 Problema

Ubica cada ejemplo en el nivel **más específico** que le corresponda (IA con reglas, Machine Learning, Deep Learning o LLM):

1. Un termostato que enciende la calefacción si la temperatura baja de 18 °C.
2. Un sistema que aprende a predecir ventas a partir de datos históricos.
3. Una red de muchas capas que identifica objetos en fotografías.
4. Un asistente que redacta correos a partir de una instrucción.

## 🪜 Pasos

1. Escribe el nivel de cada uno.
2. Dibuja el mapa de conjuntos anidados y ubica los cuatro.

## 📏 Criterios de evaluación

- Clasificación correcta de los 4.
- El mapa muestra los conjuntos contenidos unos en otros.
