# ❓ Quiz — Introducción a la IA Conversacional

## 📝 Instrucciones

10 preguntas · 5 minutos · una sola respuesta correcta salvo que se indique.

---

**1.** Un cliente escribe algo que los autores de un chatbot de reglas no previeron. ¿Qué es más probable?

- a) Responde con creatividad
- b) Responde con un mensaje genérico o de error
- c) Aprende la regla y la guarda
- d) Se apaga

**2.** Verdadero o falso: un asistente basado en LLM siempre da respuestas correctas porque fue entrenado con muchos textos.

**3.** Ordena el flujo de una conversación: (A) generación · (B) entrada · (C) respuesta · (D) interpretación con historial.

**4.** ¿Cuál es la relación correcta?

- a) Deep Learning ⊃ Machine Learning ⊃ IA
- b) IA ⊃ Machine Learning ⊃ Deep Learning
- c) Machine Learning ⊃ IA ⊃ Deep Learning
- d) Son sinónimos

**5.** Un filtro de spam que mejora aprendiendo de correos marcados por usuarios es un ejemplo de…

- a) Reglas escritas a mano
- b) Machine Learning
- c) Un chatbot de reglas
- d) Un buscador

**6.** ¿Cuál es la tarea básica de un LLM?

- a) Buscar la respuesta en una enciclopedia
- b) Predecir el siguiente token más probable
- c) Traducir a código máquina
- d) Verificar hechos

**7.** En una red neuronal, "entrenar" significa…

- a) Escribir reglas a mano
- b) Ajustar los pesos comparando con respuestas correctas
- c) Borrar capas
- d) Aumentar el volumen del equipo

**8.** ¿Para qué sirve el mecanismo de atención?

- a) Para que cada token tenga en cuenta qué otros tokens importan en la frase
- b) Para acelerar internet
- c) Para guardar el historial
- d) Para traducir a otro idioma

**9.** Verdadero o falso: una alucinación es cuando el modelo inventa información con apariencia de seguridad.

**10.** El modelo no conoce hechos posteriores a su entrenamiento. ¿Qué idea ayuda a mitigarlo?

- a) Preguntar más fuerte
- b) Darle fuentes actualizadas para consultar antes de responder (idea de RAG)
- c) Apagarlo y encenderlo
- d) Usar un chatbot de reglas siempre
