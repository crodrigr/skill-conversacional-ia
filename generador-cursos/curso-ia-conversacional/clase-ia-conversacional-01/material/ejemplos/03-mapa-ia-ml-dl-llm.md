# 💡 Ejemplo 03 — El mapa IA, ML, DL y LLM

## 🌍 Contexto

Se usan estas palabras como si fueran lo mismo. No lo son: son conjuntos anidados.

## 🧠 Concepto

```text
IA ⊃ Machine Learning ⊃ Deep Learning ⊃ LLM
```

## 🧭 Explicación paso a paso

| Nivel | Idea | Ejemplo cotidiano |
|---|---|---|
| IA | Máquinas que realizan tareas "inteligentes" | Un programa que juega ajedrez con reglas |
| Machine Learning | Aprende patrones de ejemplos | Filtro de spam que aprende de correos marcados |
| Deep Learning | ML con redes neuronales de muchas capas | Reconocer rostros en fotos |
| LLM | Deep Learning para lenguaje | Un asistente que escribe y resume textos |

**Programación tradicional vs. ML**

- Tradicional: tú escribes las reglas → el programa da resultados.
- ML: tú das ejemplos y resultados → el sistema deduce las reglas.

## 🎲 Dinámica: Adivina la siguiente palabra

Completa: *"Voy a la panadería a comprar…"*

Posibles respuestas probables: *pan*, *medialunas*, *galletas*. Es poco probable: *neumáticos*.

## ✅ Resultado esperado

Un LLM hace esto mismo a gran escala: calcula qué token es **más probable** que siga, según los patrones que vio al entrenarse. No "consulta una enciclopedia".
