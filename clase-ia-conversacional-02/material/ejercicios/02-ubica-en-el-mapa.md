# 🟢 Ejercicio 02 — Ubica en el mapa

## 📊 Dificultad

🟢 Básico

## 🎓 Resultados de aprendizaje

OA-2

## 🧩 Problema

Este mapa tiene seis palabras (coordenadas ilustrativas):

| Palabra | Vector |
|---|---|
| tren | (9, 2) |
| bus | (8, 3) |
| manzana | (2, 8) |
| pera | (3, 9) |
| uva | (2, 9) |
| barco | (9, 1) |

## 🪜 Pasos

1. Dibuja los puntos en una cuadrícula de 0 a 10.
2. ¿Qué dos grupos se forman? Ponles nombre.
3. ¿Qué palabra está más cerca de *bus*? ¿Y de *pera*?
4. ¿Qué significa que *tren* y *uva* estén lejos?

## 📏 Criterios de evaluación

- Ubica correctamente los seis puntos.
- Identifica los dos grupos y los nombra.
- Relaciona cercanía con significado parecido.
