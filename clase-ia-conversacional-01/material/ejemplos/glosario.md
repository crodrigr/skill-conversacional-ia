# 📚 Glosario — IA Conversacional

Consulta rápida de los términos del módulo, en lenguaje sencillo.

| Término | ¿Qué es? | Analogía |
|---|---|---|
| **IA conversacional** | Sistema con el que se dialoga en lenguaje natural | Un mesero que recuerda tu mesa |
| **Chatbot de reglas** | Asistente que sigue un guion escrito a mano | Un cajero con manual fijo |
| **Historial** | Lo dicho antes en la conversación, que ayuda a entender lo nuevo | La memoria de la mesa |
| **Machine Learning** | Aprender patrones a partir de ejemplos | Aprender a distinguir perros y gatos viendo fotos |
| **Deep Learning** | Machine Learning con redes neuronales de muchas capas | Una cadena de muchos pasos |
| **LLM** | Modelo entrenado con enormes cantidades de texto que genera lenguaje | Un autocompletar gigante |
| **Token** | Fragmento de texto: palabra, parte de palabra o signo | Pieza de Lego de texto |
| **Red neuronal** | Neuronas artificiales organizadas en capas | Cadena humana que pasa señales |
| **Peso / Parámetro** | Número que indica qué tanta importancia tiene una conexión | Perilla de volumen |
| **Entrenar** | Ajustar los pesos para equivocarse menos | Afinar una receta |
| **Transformer** | Arquitectura (2017) que usa atención y hace posibles los LLM | — |
| **Atención** | Mecanismo para que cada token mire a los demás y capte el contexto | Subrayar con marcador |
| **Preentrenamiento** | Etapa en que el modelo aprende el lenguaje prediciendo el siguiente token | Aprender a cocinar |
| **Ajuste** | Etapa en que aprende a responder como asistente | Aprender a atender mesas |
| **Alineación** | Etapa de mejora con evaluación humana y reglas de seguridad | Corregir según el comensal |
| **Alucinación** | Respuesta inventada que suena segura | Responder de memoria sin comprobar |
| **Sesgo** | Prejuicio heredado de los textos de entrenamiento | — |
| **Ventana de contexto** | Cantidad de texto que el modelo puede considerar a la vez | El tamaño de la mesa de trabajo |
| **RAG** | Dar documentos al modelo para consultar antes de responder | Examen a libro abierto |
