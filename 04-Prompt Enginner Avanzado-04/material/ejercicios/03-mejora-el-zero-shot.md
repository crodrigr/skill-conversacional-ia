# 🟡 Ejercicio 03 — Mejora el zero-shot

## 📊 Dificultad

🟡 Intermedio

## 🎓 Resultados de aprendizaje

OA-1, OA-2

## 🧩 Problema

Este prompt es de una pastelería ficticia, «Dulce Mañana»:

```text
Hazme una oferta.
```

## 🪜 Pasos

1. Indica **qué piezas faltan** (rol, tarea, contexto, formato, restricciones).
2. Reescribe el prompt con al menos **cuatro piezas**. Inventa datos ficticios (producto, precio, días).
3. Explica en una frase qué mejoró.

## 📏 Criterios de evaluación

- Detecta que faltan las cinco piezas.
- La versión nueva incluye al menos cuatro y usa datos ficticios.
- Explica la mejora con claridad (qué, para quién, formato).
