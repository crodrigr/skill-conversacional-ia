# 🟢 Ejercicio 07 — Elige el nivel

## 📊 Dificultad

🟢 Básico

## 🎓 Resultados de aprendizaje

OA-6

## 🧩 Problema

Elige zero, one o few-shot para cada caso y justifica con un criterio:

1. Escribir una despedida para un correo.
2. Dar las respuestas siempre en el formato `Fecha: … | Lugar: … | Hora: …`.
3. Decidir si una consulta es "Urgente" o "Normal" según reglas propias de una clínica ficticia.

## 🪜 Pasos

1. Escribe tu elección para cada caso.
2. Indica el criterio (tarea común, formato fijo, criterio propio, costo).

## 📏 Criterios de evaluación

- 1: zero-shot (tarea común).
- 2: one-shot (formato fijo).
- 3: few-shot (criterio propio).
- Cada elección va con un criterio claro.
