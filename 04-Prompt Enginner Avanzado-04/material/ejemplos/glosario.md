# 📚 Glosario — Prompt Engineering Avanzado

Consulta rápida de los términos de la sección, en lenguaje sencillo.

| Término | ¿Qué es? | Analogía |
|---|---|---|
| **Prompt** | La instrucción y la información que se entrega al modelo | La nota de encargo |
| **LLM** | Modelo de lenguaje grande que predice el siguiente token (Módulo 01) | Un autocompletado muy entrenado |
| **Token** | Fragmento de texto que el modelo procesa | Una pieza de Lego de texto |
| **Ventana de contexto** | Cantidad máxima de texto que el modelo puede considerar a la vez | El tamaño del escritorio |
| **Rol** | Quién debe "ser" el modelo al responder | El uniforme del empleado |
| **Contexto** | La información que el modelo necesita para responder | El expediente del caso |
| **Formato** | La forma en que se quiere la respuesta | El formulario que se rellena |
| **Restricción** | Lo que el modelo debe evitar | Las reglas de la casa |
| **Zero-shot** | Pedir una tarea sin ejemplos | "Hazlo" |
| **One-shot** | Pedir una tarea con un solo ejemplo | "Hazlo como este caso" |
| **Few-shot** | Pedir una tarea con varios ejemplos | "Mira los casos del manual y haz el siguiente" |
| **Ejemplo (shot)** | Un par entrada → salida dentro del prompt | Un caso resuelto |
| **Aprendizaje en contexto** | Adaptarse a lo que muestran los ejemplos del prompt sin cambiar los parámetros | Seguir la nota de hoy |
| **Etiqueta** | La categoría asignada a una entrada (Positiva, Negativa, Neutra) | La etiqueta de un archivador |
| **Caso límite** | Un ejemplo difícil, entre dos categorías | El caso dudoso del manual |
| **Alucinación** | Respuesta inventada que suena creíble | Rellenar con imaginación lo que no se sabe |
| **Parámetros** | Los valores internos que el modelo aprendió al entrenarse | Lo aprendido en la formación |
| **RAG** | Consultar documentos propios antes de responder | Examen a libro abierto |
| **Ajuste fino** | Entrenar el modelo con ejemplos propios para cambiar su comportamiento de fondo | Un curso de especialización |
| **Salida simulada** | Respuesta escrita a mano como ilustración; no sale de un modelo real | Un ejemplo de la pizarra |
