# 📚 Glosario — Ingeniería de Contexto en Modelos IA

Consulta rápida de los términos de la sección, en lenguaje sencillo.

| Término | ¿Qué es? | Analogía |
|---|---|---|
| **Contexto** | Todo lo que el modelo recibe y "ve" antes de responder | El escritorio del empleado |
| **Ingeniería de contexto** | Diseñar y mantener la información que recibe el modelo | Ordenar el escritorio |
| **Prompt engineering** | Redactar buenas instrucciones; queda dentro de la ingeniería de contexto | La nota de encargo |
| **Inferencia** | El momento en que el modelo genera una respuesta | Atender al cliente |
| **Token** | Fragmento de texto que el modelo procesa | Una hoja |
| **Tokenización** | Dividir el texto en tokens | Cortar el texto en hojas |
| **Tokenizador** | La regla que corta el texto; cambia según el modelo | El troquel |
| **Ventana de contexto** | Máximo de tokens que el modelo considera a la vez | El tamaño del escritorio |
| **Latencia** | Tiempo que tarda la respuesta | La espera del cliente |
| **Embedding** | Vector que representa el significado de un texto | Coordenadas en un mapa |
| **Espacio semántico** | Mapa donde lo parecido queda cerca | Un mapa de barrios |
| **Modelo de embedding** | Modelo que convierte textos en vectores comparables | El cartógrafo |
| **Consulta** | La pregunta o búsqueda | La petición al archivo |
| **Ampliación de la consulta** | Enriquecer la consulta antes de buscar | Buscar con más palabras clave |
| **Recuperación** | Traer fragmentos relevantes antes de responder | Ir al archivo por la carpeta |
| **RAG** | Recuperar información externa antes de generar la respuesta | Examen a libro abierto |
| **Historial** | Mensajes anteriores de la conversación | El cuaderno de la charla |
| **Memoria** | Información que se conserva entre interacciones | La libreta de preferencias |
| **Herramienta** | Algo que el modelo puede consultar o ejecutar | La caja de herramientas |
| **Estado de la tarea** | El avance actual de un proceso | La hoja de seguimiento |
| **Selección** | Elegir solo lo relevante | Dejar sobre el escritorio lo útil |
| **Compresión** | Resumir sin perder lo importante | Una nota que resume una pila |
| **Aislamiento** | Guardar fuera lo pesado y mostrar lo necesario | El archivo del sótano |
| **Trazabilidad** | Poder indicar de dónde viene la información | Anotar la fuente |
| **Agente** | Sistema que planifica, usa herramientas y mantiene estado | Un empleado con autonomía |
| **Plantilla de contexto** | Estructura de ocho apartados para diseñar el contexto | El formulario de encargo |
| **Salida simulada** | Respuesta escrita a mano como ilustración; no sale de un modelo real | Un ejemplo de la pizarra |
