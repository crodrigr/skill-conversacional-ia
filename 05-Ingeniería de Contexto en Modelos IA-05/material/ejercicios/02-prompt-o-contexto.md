# 🟢 Ejercicio 02 — ¿Prompt o contexto?

## 📊 Dificultad

🟢 Básico

## 🎓 Resultados de aprendizaje

OA-1

## 🧩 Problema

Para cada tarea, indica si es sobre todo **prompt engineering** o **ingeniería de contexto**:

1. Pedir que el asistente resuma un texto en 5 puntos.
2. Hacer que el asistente responda con las notas reales del estudiante.
3. Escribir mejor la instrucción para que use un tono formal.
4. Decidir qué parte del historial se envía y cuál se resume.
5. Elegir qué documentos de una biblioteca se recuperan antes de responder.

## 🪜 Pasos

1. Clasifica cada tarea.
2. Explica por qué la ingeniería de contexto **incluye** el prompt engineering.

## 📏 Criterios de evaluación

- Prompt engineering: 1 y 3.
- Ingeniería de contexto: 2, 4 y 5.
- Explica que el prompt es una parte de todo lo que el modelo ve.
